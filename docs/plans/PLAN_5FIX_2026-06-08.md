## Sorun 2 — Past Winners: F1DB schema fix + backfill (EN BÜYÜK İŞ, son yapılacak)

- İsimler top-level lookup'larda: `drivers[]` (`id, firstName, lastName, abbreviation`), `constructors[]` (`id, name`).

**Dosya:** `lib/f1/sources/f1db.ts`

4. `driverResultToErgast` / `qualResultToErgast`: lookup map'leri parametre al; `driverId`→`{givenName:firstName, familyName:lastName, code:abbreviation}`, `constructorId`→`{name}` çöz. `positionNumber`/`positionText`→`position` (string), `gridPositionNumber`→`grid`. **`position` mutlaka string** ("1") olmalı — `getRaceWinner` (`lib/f1/mrdata.ts`) `position==='1'` arıyor.
5. `toMRDataResults` / `toMRDataSprint`: `race.raceResults` / `race.sprintRaceResults` oku; lookup map'leri ilet.

**Dosya:** `scripts/seed-f1-history.ts`
- Satır 117/135 call site'ları yeni lookup map imzasına uydur. Satır 119 `Results.length>0` guard'ı dizi adı düzelince doğru çalışır.

## Sorun 5 — News live RSS + 15 dk in-memory cache

### 5a — Sayfayı canlı aggregate'e çevir
**Dosya:** `app/news/page.tsx`
- Satır 30: `Promise.all([getLatestNews(24), getFeaturedNews()])` → tek `const items = await aggregate({ maxItems: 100 })`.
- `featured = items.find(hasRealImage) ?? items[0] ?? null`; `rest = featured ? items.filter(i => i.id !== featured.id) : items`.
- `revalidate = 0` kalır. Kullanılmayan import'ları (`getFeaturedNews`, `getLatestNews`) kaldır; `aggregate` import et.

**`hasRealImage` reuse:** `lib/data/news.ts`'te private (satır ~88). **Export et**, sayfaya import et (tek kaynak). Parametre tipini `{ image: string }`'e daralt ki her iki `NewsItem` şeklini kabul etsin.

### 5b — 15 dk in-memory cache + stampede guard
**Dosya:** `lib/news/aggregate.ts`
- Mevcut gövdeyi `aggregateUncached()`'e taşı; **tam set** çek (iç slice'ı kaldır veya yüksek cap, ör. 200).
- Module-scope:
  ```ts
  let _cache: { items: NewsItem[]; ts: number } | null = null;
  let _inflight: Promise<NewsItem[]> | null = null;
  const TTL = 15 * 60 * 1000;
  ```
- Public `aggregate({maxItems})`:
  1. `_cache` taze (`Date.now()-_cache.ts < TTL`) → `_cache.items.slice(0, maxItems)`.
  2. `_inflight` varsa → `await _inflight` sonra slice (concurrent stampede guard).
  3. Yoksa `_inflight = aggregateUncached().then(items => { _cache={items, ts:Date.now()}; return items; }).finally(() => { _inflight=null; })`; await + slice.
- Hata/boşta cache'i zehirleme: `_inflight` reject olursa `finally`'de temizle; varsa eski `_cache`'i serve et (serve-stale-on-error); hiç cache yoksa `[]`.

**Risk/not:** Module cache **per warm instance** (serverless) — global değil. `revalidate=0` ile her cold instance bir RSS turu öder, warm 15 dk reuse eder = istenen davranış. Mevcut per-feed/total timeout (6s/12s) + `Promise.allSettled` korunur (ölü feed sayfayı kırmaz). `/news` artık `news_cache` DB'sini okumaz; home (`getLatestNews`) DB yolunda kalır — kasıtlı.
