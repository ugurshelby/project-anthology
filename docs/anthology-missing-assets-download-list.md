## Yerleştirme kuralı

1. Tablo satırındaki **Hedef path** aynen kullan (`data/stories/content.ts` path’leri sabit).
2. PNG tercih et; aynı stem’de `.svg` placeholder varsa silinebilir.
3. Aynı hikâyede iki blok aynı dosyayı paylaşmasın.
4. `stories-images` export’u path güncellemesinden sonra yeniden üret.
