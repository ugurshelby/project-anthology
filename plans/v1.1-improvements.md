## FAZ C — SEO & Güvenlik Sertleştirme  (URL-bağımsız kısım: Faz A ile birlikte/hemen ardından)

### C1 — next.config.ts: güvenlik header'ları (pragmatik CSP)
**Neden:** `headers()` yok; XSS/clickjacking/MIME-sniff koruması eksik. Dikkat: dosya `withSentryConfig`
sarılı + `tunnelRoute:"/monitoring"`; CSP Sentry/Vercel/Supabase/Cloudinary/next-image/haber-CDN'i bloklamamalı.

- [ ] `next.config.ts`: `nextConfig` objesine `async headers()` ekle (Sentry wrapper'ın İÇİNDEKİ config'e,
      `redirects`/`images` ile aynı seviyede). Tüm route'lar (`source: '/:path*'`) için:
  - `Content-Security-Policy` (pragmatik):
    - `default-src 'self'`
    - `script-src 'self' 'unsafe-inline' 'unsafe-eval'` (Next runtime + JSON-LD inline; Sentry)
    - `style-src 'self' 'unsafe-inline'` (Tailwind/inline style + next/font)
    - `img-src 'self' data: blob: https:` (next/image + haber CDN'leri + placeholder data-uri)
    - `font-src 'self' data:`
    - `connect-src 'self' https://*.supabase.co https://*.sentry.io https://*.ingest.sentry.io https://vitals.vercel-insights.com` (+ gerekirse OpenF1/Jolpica/Cloudinary; uygulamada ağ hatası çıkarsa origin eklenir)
    - `frame-ancestors 'self'` · `base-uri 'self'` · `form-action 'self'`
  - `X-Frame-Options: SAMEORIGIN`
  - `X-Content-Type-Options: nosniff`
  - `Cross-Origin-Opener-Policy: same-origin`
- [ ] Lokal `npm run build` + dev'de smoke: console'da CSP violation var mı; varsa eksik origin'i `connect-src`/
      `img-src`'ye ekle (pragmatik prensip — kırma).

### C2 — (ERTELENDİ) Absolute canonical + siteUrl.ts fallback
